# Installation

Download/extract the complete release kit and open START-HERE.html. Do not mix files
between releases or run the source checkout's unstamped installer.

- First installation supports the exact Microsoft 2023.501.541 stock version.
  Unlocking and the recovery format erase phone data. Keep recovery/account codes
  elsewhere before starting. The locked-unlock path is physically unqualified.
- Compatible beta updates support exact unmodified beta 1793371964 or this release's
  own build. Unknown/customized runtime hashes stop; do not disable that check.
- Complete setup normally. Independent workspace should appear automatically at
  Home without writing a setting or doing a layout reboot. Existing explicit OFF
  preferences are retained on update.
- Use the manual recovery menu Apply update / Apply from ADB only when prompted.
  Choose No for additional apps. Never use Enable ADB or adb reboot sideload.
- Let the helper verify recovery results/all installed images before rebooting.
  Complete setup/PIN privately, authorize USB again and finish normal verification.

The guide in the kit has the exact source/target/build hashes and troubleshooting.
Read [testing scope](TESTING.md), [known issues](KNOWN-ISSUES.md) and [stock return](RESTORE-STOCK.md) before deciding to install.
